## 판정
인샘플 통과(전략별) = 둘 다
1. CAGR ≥ KODEX200 CAGR
2. 같은 가중 방식 유니버스 대비 월(21거래일) 초과수익 NW t ≥ 2.24 (전략 2개 → 본페로니)

둘 다 불통과면 홀드아웃을 쓰지 않는다(IC 홀드아웃 포함).

홀드아웃 통과(인샘플을 통과한 전략만) = 둘 다
1. 누적수익(비용 차감) ≥ KODEX200 누적수익
2. 같은 가중 방식 유니버스 대비 누적 초과수익 > 0 (12개월이라 t 는 요구하지 않고 보고만)

통과 시 다음: `paper/portfolios.json` 에 새 이름으로 등록 → 페이퍼 6개월(기획서 7장 게이트). 실주문 없음.
