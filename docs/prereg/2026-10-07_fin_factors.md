# 사전 등록: 재무 가치·퀄리티 팩터 IC

- ID: `fin_factor_v1`
- 등록: 2026-10-07. DART 주요계정(2015~)을 수집하는 중에, 피처와 수익률을 한 번도 맞춰 보기 전에 커밋한다.
  2023년 이후 재무로 대시보드 밸류에이션·스크리너는 만들었지만 수익률과의 관계는 보지 않았다. 이후 수정 금지(바꾸면 v2).

## 데이터
- OpenDART 다중회사 주요계정(`fnlttMultiAcnt`), 연결 우선·없으면 별도 (`src/data/dart_fin.py`, `src/valuation.py`).
- 손익은 연초부터 누적값의 차이로 분기 값을 만들고 TTM = 최근 4개 분기 합(넷 다 있어야). 자본 = 자본총계.
- 순이익·자본은 비지배지분을 포함한다(주요계정에 지배주주 몫이 따로 없다).

## 시점 규칙 (누수 방지)
- 보고서 숫자를 **아는 날 = 접수일(rcept_no 앞 8자리) 다음 거래일**. 목록에 접수 시각이 없어 장 마감 뒤 공시일 수 있다고 본다.
- 한 분기의 TTM·평균 자본은 그 분기 보고서의 접수일에 안다고 본다(앞 분기들은 그보다 먼저 공시됨).
- 정정 공시가 있으면 API 는 정정본 숫자와 정정 접수일을 준다 → 아는 날은 늦어지는 쪽(보수적)이지만 숫자는 정정치다.
  최초 공시 숫자는 따로 없으므로 이 차이는 알려진 한계로 둔다.
- 마지막으로 아는 분기 말이 t 보다 15개월 넘게 지났으면 결측(오래된 재무를 끌어 쓰지 않는다).

## 피처 (t 일)
| 이름 | 정의 |
|---|---|
| `bp` | 자본총계 ÷ t 시가총액 (자본 ≤ 0 이면 결측) — PBR 의 역수, 가치 |
| `ep` | TTM 순이익 ÷ t 시가총액 (적자는 음수 그대로) — PER 의 역수, 가치 |
| `roe` | TTM 순이익 ÷ 평균 자본(그 분기와 4분기 전, 둘 다 > 0) — 퀄리티 |
| `qv` | 그날 유효 종목 안에서 `bp` 백분위 순위와 `roe` 백분위 순위의 평균 — "저PBR·고ROE" |

## 검정
- 라벨: **총수익** 선행 수익률 (t 종가 → t+h 종가, `load_panel(total_return=True)`).
- 유니버스: 시점별 시총 상위 200 + 유동성 필터(가격 기준) + 상장 252일 (div_sig_v1 과 같음).
- 지평: 20일, 60일. IC = 날짜별 스피어만, 유효 종목 30개 미만 날 제외, NW t lag 2h.
- 검정 수 4 × 2 = 8 → 본페로니(양측 5%) |t| ≥ 2.73.
- 참고 보고(판정 무관): low_vol·size 를 통제한 잔차 IC, 피처가 있는 종목 비율(커버리지).
- 생존편향 점검(판정 무관, 부록에 기록): 인샘플 유니버스 종목 중 재무가 없는 종목(상폐 등)의 비율.

## 기간·판정
- 인샘플: 2016-06-01 ~ 2025-09-29 (라벨 끝도 이 안).
- 홀드아웃: 2025-09-30 ~ 데이터 끝, **한 번만** (`--confirm`, 잠금 파일).
- 인샘플 |t| ≥ 2.73 인 것만 후보. 후보가 있어도 IC 만으로 홀드아웃을 쓰지 않는다:
  div_sig_v1 부록 2 와 같이 비용 포함 백테스트를 따로 사전 등록해 인샘플에서 먼저 점검하고,
  그것까지 통과하면 IC·백테스트 홀드아웃을 한 번의 실행으로 함께 판정한다.
- 홀드아웃 통과 = 같은 부호, NW t ≥ 1.65.
- 알려진 오염(실행 전 기록): 홀드아웃 기간은 반도체 초대형주가 이끈 좁은 급등장이었고(1년 상승 종목 29%),
  가치주에 불리했을 가능성을 이미 알고 있다. 판정 기준은 위에 고정한다.
