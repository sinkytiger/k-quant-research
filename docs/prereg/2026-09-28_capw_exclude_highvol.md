## 판정 (홀드아웃)
진행 조건: 인샘플에서 A 의 누적수익이 C 보다 낮으면 홀드아웃을 쓰지 않고 중단한다.

통과 = 아래 둘 다
1. A 누적수익(비용 차감) ≥ C 누적수익
2. A 최대낙폭(MDD) ≥ C 최대낙폭 − 5%p (C 보다 5%p 넘게 더 깊이 빠지지 않음)

보조 보고(판정에 쓰지 않음): A−B(제외 효과), A−C 월별 초과수익 NW t. 12개월이라 t ≥ 1.96 은 기대하지 않는다.

통과해도 다음 단계는 페이퍼 6개월(기획서 7장 게이트)이며 실주문은 하지 않는다.
불통과면 이 규칙은 폐기하고, 홀드아웃 결과를 보고 규칙을 고치지 않는다.
