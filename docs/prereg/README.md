# 사전 등록 문서

규칙·기간·판정 기준을 **실행 전에** 커밋하고, 결과는 같은 문서의 "부록"에만 덧붙인다(본문 수정 금지).
바꾸려면 새 ID(v2)로 새 문서를 쓴다. 커밋 시각(`git log docs/prereg/`)이 "결과를 보기 전에 정했다"는 증거다.

| 문서 | 결과 | 홀드아웃 |
|---|---|---|
| [capw_exvol_v1](2026-09-28_capw_exclude_highvol.md) 시총가중 − 고변동 20% | 인샘플 불통과 | 미사용 |
| [voltarget_v1](2026-09-28_voltarget_kodex200.md) KODEX200 변동성 타게팅 | 인샘플 불통과 (MDD 기준) | 미사용 |
| [news_sent_v1](2026-09-29_news_sentiment.md) 뉴스 제목 감성 | 탐색 불통과 (t 1.65 < 2.64) | 미사용 |
| [dart_events_v1](2026-09-30_dart_events.md) 공시 이벤트 | 인샘플 불통과 (반응이 진입 전에 끝남) | 미사용 |
| [div_sig_v1](2026-09-30_dividend_signals.md) 배당수익률 IC | 인샘플 통과 (t 3.34 / 3.00) | 백테스트와 묶음 → 미사용 |
| [div_bt_v1](2026-09-30_dividend_backtest.md) 배당 상위 20% 백테스트 | 인샘플 불통과 (유니버스 대비 t 1.11 < 2.24) | 미사용 |

공통 규칙
- 판정 기준은 결과를 보고 바꾸지 않는다. 결과를 본 뒤 발견한 결함은 부록에 적고 판정은 그대로 둔다.
- 여러 검정은 본페로니로 기준을 올린다. 중첩 수익률의 t 는 Newey-West.
- 홀드아웃은 인샘플을 통과한 것만, `--confirm` 으로 한 번. 잠금 파일(`outputs/prereg_*_holdout.json`)로 재실행을 막는다.
- 팩트체크(`docs/factcheck/`)의 규칙형 주장 검증은 2025-09-29 이전 데이터만 쓴다. 예측형 주장의 사후 가격 대조는 전략 탐색이 아니므로 홀드아웃 구간 가격을 쓰는 예외로 둔다(`docs/factcheck/factcheck-기획.md` 2절).
