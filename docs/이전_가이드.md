# 새 PC 로 옮기기 · 데이터 백업

## 무엇이 어디에 있나

| 항목 | 위치 | 새 PC 에서 |
|---|---|---|
| 코드·문서·분석 노트 | `OneDrive\바탕 화면\K-quant` (+ GitHub 비공개 저장소) | OneDrive 동기화 또는 `git clone` |
| API 키 `.env` | K-quant 폴더 (Git 에는 없음, OneDrive 에만) | OneDrive 로 같이 온다 |
| 수집 데이터 | `C:\KQuantData` (`.env` 의 `KQ_DATA_DIR`) | **백업 zip 을 푼다** |
| 예약 작업 | Windows 작업 스케줄러 | 스크립트로 다시 등록 |

## 데이터 백업 (자동)

- 매주 토요일 09:30 `run_weekly.bat` → `scripts/backup_data.py` 가 `C:\KQuantData` 를 zip 으로 묶어
  `OneDrive\KQuantBackup\kquant-data-YYYYMMDD-HHMM.zip` 에 둔다. 최근 2개만 남긴다(`.env` 의 `KQ_BACKUP_KEEP` 로 변경).
- 넣지 않는 것: 파이썬 가상환경(`venv*`, 다시 설치), KIS 접속 토큰(`.kis_token_*`, 다시 발급).
- 지금 바로: `python scripts/backup_data.py` · 목록: `python scripts/backup_data.py --list`
- 외장 디스크로: `python scripts/backup_data.py --dest E:\KQuantBackup`
- 지금 설정: `.env` 의 `KQ_BACKUP_DIR` 에 OneDrive 와 구글 드라이브(`G:\내 드라이브\KQuantBackup`) 두 곳. 한 번 만들고 두 번째는 복사.
- 새 PC 에서 구글 드라이브 쪽 백업으로 복원: `python scripts/restore_data.py "G:\내 드라이브\KQuantBackup\kquant-data-...zip"`

## 새 PC 로 옮기는 순서

1. **옛 PC 예약 작업 끄기** (두 PC 가 동시에 돌면 KIS 토큰이 충돌한다)
   - 관리자 PowerShell: `Unregister-ScheduledTask -TaskName KQuant-Daily,KQuant-Weekly -Confirm:$false`
2. 옛 PC 에서 마지막 백업: `python scripts/backup_data.py`
3. 새 PC 에 OneDrive 로그인 → `바탕 화면\K-quant` 와 `KQuantBackup` 이 내려올 때까지 기다린다
4. Python 3.12 설치 → K-quant 폴더에서 `python -m pip install -r requirements.txt`
5. Git·GitHub CLI 설치 → `gh auth login` (분석 노트 자동 push 용)
6. `.env` 의 `KQ_DATA_DIR` 경로 확인 (예: `C:\KQuantData`) → 데이터 복원:
   `python scripts/restore_data.py --latest`
7. 점검: `python scripts/collect_universe.py --check --status` (API 키·데이터·생존편향 안전 여부)
8. 관리자 PowerShell 에서 예약 등록: `scripts\setup_schedule.ps1`
9. 다음 날 `logs\daily_날짜.log` 의 모든 단계가 `exit 0` 인지 확인

## 백업이 없을 때 (최후 수단)

`python scripts/collect_universe.py --backfill --period 10y --markets stk ksq` 로 KRX 스냅샷을 다시 받는다.
하루 KRX 한도(약 9,500건) 때문에 이틀 정도 걸린다. KIS 수급(`collect_flows.py --backfill`)·뉴스(`collect_news.py --backfill`)·DART(`collect_dart.py --backfill`)·배당(`collect_dividends.py`)도 다시 받는다.
KIS 뉴스 제목은 약 1년 전까지만 촘촘해서 그보다 오래된 이력은 되찾지 못한다.
