# 증시 콘텐츠 주장 팩트체크 — 방법론 기획서

작성일 2026-10-07 · 대상 저장소 `K-quant` (모듈 `factcheck`) · 상태 **승인 v1.3 (2026-10-07)**

변경 이력
- v1.0 (2026-10-07) 승인. 채널은 구독자 상위 10개 기계적 선정, 공개물은 채널 익명 처리(10절)
- v1.1 (2026-10-07) 수집 도구를 transcriptapi.com에서 YouTube Data API v3(채널·영상·게시일) + yt-dlp(자막)로 변경. 이유: 유료 크레딧 없이 수집하고, 게시일·구독자 수를 상대 표기가 아닌 정확한 값으로 받기 위해. 3분 이하 영상(쇼츠) 제외 추가
- v1.2 (2026-10-07) 채널 선정에 언론사 제외 단어와 제목 기반 주제 기준(6단계) 추가. 이유: 후보 상위에 정치·시사, 언론사, 미국 주식 중심 채널이 섞였는데 3.1 주제 기준을 확인하는 기계적 단계가 없었음. 채널 목록 고정 전, 주장 내용을 보기 전에 변경
- v1.3 (2026-10-07) 언론사 제외 단어 보강(뉴스, NEWS, 방송사 이름, 대소문자 무시)과 구간 영상 상한 3,000개 추가. 이유: 시험 실행에서 방송사 뉴스 채널(MBCNEWS)이 제외 규칙을 통과해 하루 수백 개 영상 목록을 넘기느라 할당량을 소모. 시험 실행은 첫 채널에서 중단되어 선정 결과는 보지 않은 상태에서 변경. 후보 검색은 실행마다 결과가 달라 `candidates.csv`를 기준 스냅샷으로 삼는다

## 1. 분석 목적과 질문
증시 유튜브에서 반복되는 "검증할 수 있는 투자 주장"을 뽑아 K-quant 데이터로 사전 등록 후 검증하고, 주장마다 판정을 공개한다. 사람이 아니라 주장을 평가한다.

| | 질문 |
|---|---|
| **Q1** | 수집한 투자 주장 중 데이터로 검증할 수 있는 형태(규칙형·예측형)는 몇 %인가 |
| **Q2** | 검증한 규칙형 주장 가운데 지지·근거 없음·반대 판정의 비율은 얼마인가. 거래비용을 넣으면 어떻게 바뀌는가 |
| **Q3** | 예측형 주장(특정 종목·지수의 가격·방향 예측)의 적중률은 얼마인가 |
| **Q4** | 주장 유형(수급, 기술적 지표, 공시·이벤트, 계절성, 밸류에이션)별로 판정 분포가 다른가 |

## 2. 데이터 수집
**수집 대상** 사전에 고정한 국내 증시 유튜브 채널의 영상 자막 / 검증용 데이터는 K-quant 기존 데이터
**수집 방법** 채널·영상 정보와 게시일은 YouTube Data API v3, 자막(타임스탬프 포함 json3)은 yt-dlp로 받아 `KQ_DATA_DIR/factcheck/`에 원본 저장. 자막은 저장소에 커밋하지 않는다. Claude가 자막에서 주장을 추출해 `docs/factcheck/claims/`에 구조화 JSON으로 커밋.

| 변수 | 원자료 | 기관 · 코드 | 주기 | 수집 구간 |
|---|---|---|---|---|
| 영상 목록, 게시일, 길이 | 업로드 재생목록 `playlistItems.list`(videoPublishedAt), `videos.list`(duration) | YouTube Data API v3 | 영상 | 2025-10-01 ~ 2026-09-30 게시 |
| 자막 | 한국어 수동 자막, 없으면 자동 생성 자막(json3) | yt-dlp | 영상 | 동일 |
| 가격·시가총액·유니버스 | K-quant 일별 스냅샷, 수정주가 | KRX Open API | 일 | 2015-09 ~ 2025-09-29 (홀드아웃 이전) |
| 투자자별 순매수 | K-quant 수급 | KIS Open API | 일 | 동일 |
| 공시 | K-quant 공시 | DART OpenAPI | 이벤트 | 동일 |
| 배당·총수익 | K-quant 총수익 가격 | KIS 예탁원 배당일정 | 일 | 동일 |
| 예측형 주장 사후 대조 가격 | K-quant 일별 스냅샷 | KRX Open API | 일 | 주장 게시일 ~ 주장 기한 |

자막만 비공식 도구(yt-dlp)를 쓰는 이유: YouTube Data API의 자막 다운로드는 영상 소유자만 쓸 수 있어, 남의 영상 자막을 받는 공식 수단이 없다. K-quant의 "공식 API만" 원칙에 대한 예외이며, 로그인이 필요 없는 공개 자막만 받는다. 차단을 피하려고 영상 사이에 3~6초 대기하고, 받은 자막은 건너뛰어 재개한다. 자막이 없는 영상은 표식을 남기고 6절 규칙대로 제외한다.

3분 이하 영상은 세지 않는다. 쇼츠는 조건·기간을 갖춘 주장이 드물고, 활동 기준(영상 50개)을 부풀린다.

규칙형 주장의 검증 구간을 2025-09-29까지로 막은 이유: K-quant의 홀드아웃(2025-09-30 이후)은 자체 전략 검증에 한 번만 쓰기로 잠겨 있다. 팩트체크가 그 구간을 보면 이후 K-quant 홀드아웃 검증이 오염된다.

예측형 주장은 특정 날짜 이후의 실제 가격과 대조하는 것이라 홀드아웃 구간 가격을 쓴다. 전략 탐색이 아니라 사후 대조이므로 잠금 대상에서 제외하고, 이 예외를 `docs/prereg/README.md`에 한 줄 남긴다.

### 3.1 채널 선정 기준
| 기준 | 값 | 이유 |
|---|---|---|
| 주제 | 국내 주식 시황·종목·매매기법이 주 콘텐츠 | 검증 데이터가 국내 주식만 있음 |

선정 절차. 사람이 고르지 않고 아래 순서를 코드로 실행한다.

| 단계 | 처리 | 이유 |
|---|---|---|
| 1. 후보 수집 | `search.list`(type=channel, regionCode=KR, relevanceLanguage=ko, 50건/페이지)로 고정 검색어 6개(주식, 주식투자, 증시, 국내주식, 종목추천, 시황) 각 3페이지 결과의 합집합 | 유튜브에 구독자 순위 API가 없어 검색으로 후보군을 만듦 |
| 2. 구독자 수 | `channels.list`의 `statistics.subscriberCount`. 구독자 수를 숨긴 채널은 제외 | API가 공개하는 값(유효숫자 3자리로 반올림됨)을 그대로 씀 |
| 3. 이름 제외 | 채널명·설명에 증권, 자산운용, 투자증권, 거래소, 리딩, 유료방, 카톡방, 방송, Biz, 경제TV, 한경, 매경, 머니투데이, 뉴스공장, 뉴스, NEWS, KBS, MBC, SBS, JTBC, YTN, MBN, TV조선, 채널A가 있으면 제외(대소문자 무시) | 3.1 제외 기준(공식·리딩방·언론사 계열)을 기계적 규칙으로 |
| 4. 활동 | 수집 구간 게시, 3분 초과 영상 50개 이상. 업로드 목록이 3,000개를 넘으면 탈락(too_many_videos) | 3.1 활동 기준. 상한은 하루 8개 초과 업로드하는 클립·언론사형 채널을 걸러 할당량을 지키기 위함 |
| 5. 주제 | 수집 구간 영상(3분 초과) 제목 중 국내 주식 단어 포함 비율 ≥ 40%, 그리고 해외·코인 단어 포함 비율 < 국내 비율 | 3.1 주제 기준을 기계적으로 확인. 제목은 4단계에서 이미 받아 추가 비용 없음 |
| 6. 선정 | 남은 후보 중 구독자 상위 10개 | |

5단계 단어 목록. 국내: 주식, 종목, 코스피, 코스닥, 증시, 국장, 매수, 매도, 차트, 수급, 공시, 상한가, 하한가, 테마주, 급등주, 삼성전자, 하이닉스, 2차전지. 해외·코인: 미국, 미장, 나스닥, S&P, 다우, 뉴욕증시, 엔비디아, 테슬라, 애플, 팔란티어, 비트코인, 코인. 40%와 단어 목록은 채널별 비율을 보기 전에 정한 초기값이며, 채널 목록 고정 후에는 바꾸지 않는다. 채널별 비율은 `selection_log.csv`에 남긴다.

규칙 3에 걸리지 않은 공식·리딩방 채널이 남으면, 최종 10개를 커밋하기 전에 사용자가 제외 사유를 적어 한 번만 빼고 11번째로 채운다. 이 수작업 제외는 사유와 함께 기록한다.

채널 목록은 자막 수집 전에 고정하고 이후 바꾸지 않는다. 결과를 보고 채널을 넣고 빼면 표본 선택 편향이 생긴다. 목록 원본은 익명 처리(10절) 때문에 저장소 밖 `KQ_DATA_DIR/factcheck/channels.json`에 두고, 그 파일의 SHA-256 해시를 `docs/factcheck/channels.sha256`으로 커밋한다. 커밋 시각과 해시가 사전 고정의 증거다.

## 4. 변수 정의

### 4.1 주장 분류

| 기호 | 분류 | 정의 | 처리 |
|---|---|---|---|
| RULE | 규칙형 | 조건과 결과가 있는 일반 규칙. "외국인이 5일 연속 순매수하면 다음 달 오른다" | 과거 데이터로 백테스트 |
| FORECAST | 예측형 | 특정 대상·방향·기한이 있는 단발 예측. "삼성전자 연말까지 10만 원 간다" | 기한 도래 후 실제 가격과 대조 |
| VAGUE | 검증 불가 | 조건·기간·대상 중 하나라도 정량화 불가. "좋은 기업은 결국 오른다" | Q1 집계에만 사용 |
| NO_DATA | 데이터 없음 | 검증 가능하지만 필요한 데이터가 K-quant에 없음 (예: 신용잔고, 해외주식) | 판정하지 않고 사유 기록. 다른 소스로 대체하지 않음 |

### 4.2 주장 레코드 필드

| 필드 | 내용 |
|---|---|
| claim_id | 채널 라벨 + 영상 순번 + 주장 순번 (영상 ID는 내부 레지스트리에만) |
| video_url_ts | 영상 링크 + 발언 시작 타임스탬프 |
| quote | 원문 발언 요약 인용, 15단어 이내 |
| class | RULE / FORECAST / VAGUE / NO_DATA |
| category | 수급 / 기술적 지표 / 공시·이벤트 / 계절성 / 밸류에이션 / 기타 |
| signal | RULE: 정량화한 조건 (예: `foreign_net_buy_days >= 5`) |
| universe | 대상 유니버스. 명시 없으면 K-quant 시총 상위 200 |
| horizon_d | 보유 기간(거래일). 명시 없으면 4.3 기본값 |
| direction | +1 상승 / −1 하락 |
| target | FORECAST: 목표 가격·수익률과 기한 |
| assumptions | 모호한 표현을 정량화하며 넣은 가정 (예: "단기" → 20거래일) |

### 4.3 판정 지표

| 기호 | 변수 | 계산식 | 이렇게 정의한 이유 |
|---|---|---|---|
| t_sig | 신호일 | 조건이 t일 종가 기준으로 처음 충족된 날 | K-quant 룩어헤드 금지 원칙과 동일 |
| ER | 초과수익률 | 종목 총수익률[t+1 종가 → t+1+h 종가] − 같은 구간 유니버스 동일가중 총수익률, %p | t+1 종가 진입은 K-quant 기본 체결 규칙. 시장 전체 상승분을 빼야 주장의 고유 효과가 보임 |
| ER_net | 비용 차감 초과수익률 | ER − 왕복 비용 0.3%p | 0.3%는 가정값. 실제로 따라 할 때의 성과 |
| t_ER | 검정통계량 | 신호일 기준 월별 평균 ER의 t값 (Newey-West, lag = h/20 올림) | 겹치는 보유 기간의 자기상관 보정 |
| N_ev | 이벤트 수 | 검증 구간 신호 발생 건수 | 30건 미만이면 판정 불가 |
| HIT | 예측 적중 | FORECAST: 기한 안에 목표에 도달했으면 1, 아니면 0. 방향만 있으면 기한 시점 수익률 부호 일치 여부 | 단발 예측은 통계 검정 대신 적중 여부로 |

horizon 기본값: "단기" 5거래일, 표현 없음 20거래일, "중장기" 120거래일. 기본값을 쓴 주장은 다른 두 기간 결과도 같이 보고한다.

### 4.4 판정 라벨 (규칙형)

| 라벨 | 조건 |
|---|---|
| 지지 | 주장 방향과 ER 부호 일치, t_ER ≥ 2.0, ER_net > 0 |
| 약한 지지 | 방향 일치, 1.0 ≤ t_ER < 2.0, 또는 t_ER ≥ 2.0이지만 ER_net ≤ 0 |
| 근거 없음 | \|t_ER\| < 1.0 |
| 반대 | 주장 반대 방향으로 t_ER ≥ 2.0 |
| 판정 불가 | N_ev < 30 |

여러 주장을 한꺼번에 검정하므로 K-quant 공통 규칙(`docs/prereg/README.md`)대로 본페로니 보정 기준을 같이 적용한다. 라벨은 주장 하나를 따로 볼 때의 기준(t 2.0)으로 붙이고, 본페로니 기준을 넘는지를 별도 열로 표시한다. 보조로 Benjamini-Hochberg q값(10%)도 적는다.

## 5. 주장 추출 사양

Claude가 자막을 읽고 주장을 뽑는다. 사람이 아닌 모델이 추출하므로 일관성 규칙을 먼저 고정한다.

| 항목 | 처리 | 목적 |
|---|---|---|
| 지시문 | `src/factcheck/prompts/extract_claims_v1.md` 하나만 사용 | 판단 기준 고정 |
| 단위 | 영상 1개 = 1회 처리 | 문맥 유지 |
| 인용 | 원문 발언을 15단어 이내로 요약 인용하고 타임스탬프 필수 | 왜곡 방지·저작권 |
| 정량화 | 모호한 표현을 수치로 바꿀 때마다 `assumptions`에 기록 | 해석 재현성 |
| 중복 | 같은 채널의 같은 규칙은 하나로 합치고 등장 횟수 기록 | 반복 주장 가중 |
| 광고·협찬 | 광고 구간 발언 제외 | 주장이 아닌 홍보 |

## 6. 제외·결측 규칙

| 규칙 | 적용 |
|---|---|
| 자막 없음·자막 품질 불량(숫자 인식 오류로 조건 판독 불가) | 제외, 건수 기록 |
| 해외주식·코인·원자재 주장 | NO_DATA (v1 범위 밖) |
| 개별 종목 추천에 기한·목표가 둘 다 없음 | VAGUE |
| 시청자 질문 낭독, 타인 의견 소개 | 채널 본인 주장이 아니면 제외 |
| 같은 규칙의 변형(5일 vs 3일 연속) | 발언된 수치 그대로 하나씩. 더 나은 수치를 찾아 바꾸지 않음 |
| 검증 구간에 데이터가 없는 기간 | 그 기간 신호는 계산 안 함 |

## 7. 검증 계획

| 대상 | 방법 |
|---|---|
| 추출 정확도 | 무작위 50개 주장을 사람이 영상 타임스탬프에서 직접 확인 (인용·조건·방향) |
| 추출 일관성 | 영상 10개를 별도 세션이 독립 추출, class·category Cohen's kappa |
| 신호 구현 | 주장마다 신호 발생일 5건을 수작업 계산과 대조하는 pytest |
| 사전 등록 | 각 규칙형 주장의 signal·horizon·판정 기준을 `docs/prereg/factcheck/`에 커밋한 뒤 실행. 커밋 시각이 결과 확인 전이어야 함 |

## 10. 서술 규칙

- 사람이 아니라 주장을 평가한다. "틀렸다" 대신 4.4 판정 라벨을 쓴다.
- 채널은 익명으로 공개한다. 공개물에는 채널을 "채널 A ~ J"로만 표시하고, 라벨은 선정 후 무작위(seed 42)로 붙여 구독자 순서가 드러나지 않게 한다.
- 영상 링크, 타임스탬프, 원문 인용은 채널을 특정할 수 있으므로 내부 레지스트리(`KQ_DATA_DIR/factcheck/`)에만 둔다. 공개물에는 주장을 다시 풀어 쓴 문장만 싣는다.
- 저장소의 `docs/factcheck/claims/`에는 채널 라벨과 풀어 쓴 주장만 커밋한다. 채널명·영상 ID는 커밋하지 않는다.
- 내부 레지스트리의 인용은 15단어 이내로 제한한다.
- 정량화 과정에서 넣은 가정을 결과 옆에 반드시 적는다. 해석이 다르면 결과도 달라질 수 있음을 밝힌다.
- 채널별 순위표는 만들지 않는다. 판정 분포는 주장 유형별로만 집계한다.
- 과거 검증 결과는 투자 권유가 아니라는 문구를 붙인다.
